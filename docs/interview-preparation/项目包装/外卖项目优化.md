校园订餐/外卖系统是最常见的烂大街的项目，用的人可以说是非常非常之多！个人是不太建议使用校园订餐/外卖系统作为自己的项目经历的，因为你很难和别人形成差异化，也就没办法在面试中脱颖而出。不过，这个项目作为学习项目还是不错的。

有很多同学也没有其他项目，只能用校园订餐/外卖系统的话，那我这里也给一些建议，帮助你更好地在简历中去展示这个项目。

👉项目介绍：为校园商家提供的一款外卖/点餐平台。商家可以对商品、套餐进行管理，学生可以在小程序端下单。

👉包装建议：你可以将这个项目包装成校园点餐系统或者是接的餐厅扫码点餐系统的外包，项目名称一定不要用原项目名称，核心职责也不要完全按照原教程写，能多改改就多改改，尽量让面试官少看到点原项目的影子。

👉技术栈：SpringBoot + Spring Security + MySQL + Redis + MyBatis + Nginx

👉核心职责（原项目常见描述）：

1. 基于 SpringSecurity + JWT 实现了登录认证，权限模型使用业界主流的 RBAC。
2. 参与项目用户、商品、订单等模块的开发，基于 Spring 状态机实现订单状态流转。
3. 基于 AOP 实现公共字段（例如创建时间、创建人）的自动填充功能，减少代码，降低耦合。
4. 使用 Redis 缓存经常使用的高频数据例如热门商品数据等，避免数据库访问压力过大。
5. 基于布隆过滤器避免缓存穿透，使用 SpringTask 定时任务实现缓存预热来避免缓存雪崩。
6. 通过 WebSocket 实现来单提醒和客户催单的功能。
7. 使用 SpringTask 实现订单状态定时处理，超时自动取消订单。
8. 基于 Swagger 生成接口 API 文档，集成 Knife4j 实现 Swagger 文档增强。
9. 基于 Linux 系统部署项目，搭建 MySQL、Redis 环境。引入 Nginx 部署前端项目，实现前后端分离的部署方式。

👉可添加/修改的点（我补充的一些可形成差异化的描述）：

1. 基于 AOP 实现统一的日志管理和全局异常处理，自定义枚举类统一返回格式。
2. 基于阿里云 OSS+CDN 实现了稳定快速的图床。
3. 基于 Redis 分布式锁+状态机（订单状态）实现下单和支付的幂等设计。
4. 基于 Elasticsearch 实现店铺和商品的全文检索，整合 Canal + RabbitMQ 将 MySQL 增量数据（如店铺信息、商品信息）同步到 Elasticsearch。
5. 基于 Redisson 内置的延时队列 RDelayedQueue +状态机实现超时订单取消功能。
6. 基于 EasyExcel 实现店铺运营数据（例如 30 天的订单数据）的导出。

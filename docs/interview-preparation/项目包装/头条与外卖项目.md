黑马头条和外卖系统这俩是校招生面试用的最多的烂大街的项目。外卖系统的简历编写简历已经介绍过，地址：https://t.zsxq.com/18J4mYBxB 。

尽量不要用这个项目，如果实在没有其他项目的话，这里也给一些建议，帮助你更好地在简历中去展示这个项目。

👉项目介绍（提供了两个模板，自己参考着修改即可，不要照搬）：

1. 供学校师生使用的校园新闻网站。用户可以在该平台发布、查看和搜索文章，管理员可以管理文章和用户。
2. 专门服务程序员的交流社区。用户可以在该平台发布、查看和搜索文章，管理员可以管理文章和用户。

👉包装建议：

1. 你可以将这个项目包装成技术交流社区项目而不是头条/咨询类项目，项目名称一定不要用原项目名称，核心职责也不要完全按照原教程写，能多改改就多改改，尽量让面试官少看到点原项目的影子。
2. 原项目是微服务架构，你完全可以讲起包装成单体架构，我后面提供的核心职责介绍模板就是基于单体架构写的，不涉及微服务相关的内容。

👉技术栈（根据实际项目进行调整，单体项目就不要包含 SpringCloud 了）：SpringBoot + SpringCloud + MySQL + MybatisPlus + Redis + MongoDB + Kafka + Jenkins + Minio + Elasticsearch

👉核心职责（原项目常见描述）：

1. 基于 SpringSecurity + JWT 实现了登录认证，支持账号密码和手机验证码登录，权限模型使用业界主流的 RBAC。
2. 使用 Redis 缓存经常使用的高频数据例如热门文章、字典数据等，避免数据库访问压力过大，提高访问速度。
3. 通过 Thymeleaf 模板引擎实现页面静态化，将静态化页面保存在 Nginx，提高响应速度，减轻服务器压力。
4. 基于 Redis 的 Sorted Set（有序集合）数据类型来维护文章排行榜（根据文章的综合信息计算热度）。
5. 基于 AOP 实现统一的日志管理和全局异常处理，自定义枚举类统一返回格式。
6. 基于 AOP 实现公共字段（例如创建时间、创建人）的自动填充功能，减少代码，降低耦合。
7. 利用 RabbitMQ 的死信队列实现延迟队列效果，实战文章的定时发布功能。
8. 基于 MinIO 搭建高性能文件服务器，存储系统图像、视频等文件资源。
9. 用 OCR 技术，实现图文识别功能，将图片中的文字提取，并进行录入；
10. 使用 Elasticsearch 对文章进行搜索，实现关键词搜索功能。整合 Canal + RabbitMQ 将 MySQL 增量数据（如文章数据）同步到 Elasticsearch。
11. 基于 DFA 算法实现敏感词过滤并集成到文章审核模块，整合 Tess4J 实现图片文字识别功能。
12. 基于 Swagger 生成接口 API 文档，集成 Knife4j 实现 Swagger 文档增强。
13. 基于 Linux 系统部署项目，搭建 MySQL、Redis 环境。引入 Nginx 部署前端项目，实现前后端分离的部署方式。

👉可添加/修改的点（我补充的一些可形成差异化的描述）：

1. 引入第三方登录，例如 Github、Gitee、微信，具体思路可以参考我在星球的分享：https://t.zsxq.com/18ZIzSBPH 。
2. 基于 Redisson 内置的延时队列文章定时发送功能而不是 RabbitMQ 的死信队列。如果你把这个项目包装单体项目的话，就不要引入分布式消息队列了。如果还是想要基于 RabbitMQ 来实现延时队列的话，更推荐 RabbitMQ 延迟队列插件这种方式，效果更好。
3. 基于 Redis 的 HyperLogLog 数据类型实现了 UV 和 PV 的统计。
4. 密码加密建议加密哈希算法+ Salt（例如 SHA256，建议每个用户的 Salt 值不同） 或者慢哈希（例如 Bcrypt，更推荐这种方式），具体思路可以参考我在星球的分享：https://t.zsxq.com/18oT6LTuy 。
5. 基于 Redis 的 Hash 数据类型保存点赞信息，通过定时任务将缓存中的数据同步到数据库，实现高性能点赞（可参考：点赞模块设计 - Redis缓存   定时写入数据库实现高性能点赞功能-腾讯云开发者社区-腾讯云 )，注意大 key 问题）。
